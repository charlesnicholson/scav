How a drawing is found

The search: rows, moves and kicks

scav lays a chart out many thousands of times with slightly different inputs and ships the cheapest drawing; the search is deterministic throughout.

A drawing is a pure function of (row, pins). A row is one setting of four whole-chart sizing knobs. A pin is one recorded decision the phases must honour; there are seven kinds: rank, cut, reverse, face, orient, side and fold. Pins are inputs, not patches, so trying a move means laying out again with one more pin and undoing it means dropping the pin: no transactions, no rollback. Pins name states and transitions by id, because node indices change between layouts.

This makes every drawing a reproducible counterfactual: scav dump --layout prints a drawing's row and pins as flags, and --no-search with those flags redraws it exactly. Edit one flag to get the drawing a reader wants and score it: if it is cheaper, the search lacks a move; if dearer, the objective is wrong.

Level 2: sixteen rows

Level 2 is a fixed table of 16 rows; row i flips the knobs named by i's set bits. Row 0 is the profile as given, and the run fails if it is not viable. Every row is scored under the caller's profile, so all compare on one scale.

Every viable row is searched to convergence, and the cheapest result ships (ties to the lower row). Picking by starting cost would be wrong: on bottler, the row with the best start finishes 51% dearer than row 0.

Level 1: steepest descent over pins

The incumbent is the current best (row, pins). Each round lays out every move the incumbent allows, each a candidate with one more pin, in parallel; it takes the single best strictly improving move (ties to the earliest) and repeats until nothing improves. A candidate that is not viable or needed the inflation retry is never taken.

Each move kind has its own budget of 1,024 scored moves over the whole search, so no kind starves another. A face move that cannot move its seat is charged but not scored.

Kicks: iterated local search

Greedy descent stops in the first basin it finds, and some structural changes pay off only after the search adapts to them. A kick applies one, searches to convergence, and keeps the result only if the converged cost is cheaper; unlike simulated annealing, there is no temperature to tune.

  • Kinds: reverse a cyclic segment; turn a frame to run down; flip whether a frame is folded. Turns and folds are allowed only in rounds "with turns".
  • Warm start: the incumbent's pins minus the kicked frame's own rank, cut, face, side and fold pins, plus the kick's pin, then Level 1 scoped to that frame. A round's kicks run in parallel.
  • Reduction: take each frame's best improving kick. If several frames have one, try them together; if that loses to the best single kick, take the single and rest each other winner on top, keeping it if it still improves. Repeat until no kick improves, then one unscoped settle search.
  • Two schedules run from each row: A allows turns from the start; B runs reversals alone first. B is kept only if strictly cheaper; neither dominates.
  • Rows whose converged drawings are identical kick only once.

Refold and the search memo

A final refold search runs Level 1 again from each row's pins with fold-cut moves added, kept only if strictly cheaper. A Level 1 search is a function of its inputs, so the search memo stores whole searches by those inputs and replays a repeated one from its result. Level 1 provides most of the gain and kicks most of the CPU time.
