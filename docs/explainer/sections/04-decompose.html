Phase 0

Decompose: frames, segments, ports

Every transition is cut at each border it crosses, leaving one flat graph per submachine, joined to the others only at ports.

A frame is one submachine laid out as its own layered graph: a region, a composite's submachine, or a document root. It is the unit that is ordered, sized, run in parallel and reused between candidates. In its parent's frame, a composite state is a plain node.

A transition whose ends lie in different frames is split at every border it crosses. Each piece is a segment in exactly one frame; each cut is a port on the crossed state's border. Long hierarchical edges become a matter of ordering ports along each composite's sides, and a long edge pulls on every level it passes, with no weight needed.

How a transition is split

  1. Skip dead transitions, and internal or local self-transitions, which have no route.
  2. List each end's ancestors, innermost first, and strip the part they share.
  3. If the source encloses the destination, an internal or local transition starts on the source's inner face; an external one leaves the source and re-enters it.
  4. Exit the source's chain, innermost first; the source itself is exited only by an external transition.
  5. If the chains diverge into two submachines of one state, cross the separator between those regions instead of the state's border; that middle segment is routed in the source region's frame.
  6. Enter the destination's chain, outermost first. If the destination encloses the source, end on its inner face.
  7. Emit one port per crossing and one segment per consecutive pair of ends, each in the frame it lies in.

Each segment end is a port, an endpoint state's box, or an endpoint's inner face. In ordering, each port on a frame's border becomes a boundary node: exits on the trailing edge, entries on the leading one.

A transition's label belongs to the segment in its lowest common ancestor (LCA) frame, the innermost submachine holding both ends. Ports and segments have stable ids derived from the model, never from how work was split.

RuleCutting at borders keeps each submachine independently orderable and keeps every long edge, which ELK's two modes cannot do together. Phase 0 records what kind each segment end is; later phases never infer it.
