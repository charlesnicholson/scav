Glossary

Every term this page uses, in one line each, with a link to the section that explains it.

Anchor (label)
The point a label is pulled toward: the midpoint of its route's longest horizontal leg, else of its longest leg. The Manhattan distance from the box's centre to it is the second placement key. → labels
Attachment point
One of eight points on a label box (four side midpoints, then four corners) where the leader ends. → labels
Bend
A route vertex where the direction changes. Tier 2 charges 512 per bend on readable. → cost
Bend node
A phase-1 dummy node that chains a multi-rank edge through an intermediate rank; the router treats it as a hard waypoint. → order
Bend penalty
The router's cost for switching between its horizontal and vertical planes: one rank_sep (576 units). → route
Boundary node
A phase-1 node standing for a port (or an inner-face end) on its frame's edge: exits on the trailing border, entries on the leading one. → decompose
BoxSpace
The space request per state and submachine: min_w, h_before, h_after. → intro
Brandes–Köpf (BK)
Linear-time placement across the ranks: four alignment passes, compaction, and a median-average combine. scav follows the 2020 erratum. → size
Candidate
One full evaluation, phases 1–3 plus cover and cost, for one row and one set of pins. → pipeline
Chaining / cut
Replacing a multi-rank edge by a chain through bend nodes. A cut (ChainCut) leaves the edge unchained so the router draws it freely. → order
Chart cover
Growing the chart rectangle over every route point and label before scoring, so area and aspect price the canvas that ships. → pipeline
Choice
A pseudostate drawn as a diamond inscribed in its box; routes meet it at a face midpoint. → intro
Clearance
The router's bumper around obstacles, node_sep / 3 = 96 units: no segment comes closer to a box. → route
Composite state
A state with at least one submachine. With two or more it is concurrent. → intro
Concurrent state
A composite with two or more submachines (regions), which run at once and are drawn side by side. → intro
Corridor
The collinear length two different routes share, less their common final leg (the trunk). Weight 48 per em. → cost
Cost (Tier 0, 1, 2)
The objective, compared lexicographically: Tier 0 counts forbidden things, Tier 1 (unused) hints, Tier 2 a weighted sum of thirteen terms. → cost
Crowding
Two lanes of different routes closer than an em; priced continuously, falling to zero at one em apart. → cost
DAR
Desired aspect ratio, an integer pair: 16:10 on readable. → size
Decompose (phase 0)
Cutting every transition at the borders it crosses into segments and ports, leaving one flat graph per submachine. → decompose
Degraded route
A net the router could not route even after inflation: drawn as a straight line and reported as RouteDegraded. → pipeline
Determinism contract
Layout output is a function of the C++ abstract machine: the same bytes from any conforming toolchain, platform and thread count. → principles
Em
font_size_grid, 192 units (12 pt) on readable: the unit Tier 2 lengths are scored in, and em² for areas. → cost
Face (move)
Which side of a box a route end leaves or enters by; a FacePin fixes it. → search
Facing pass
After the first sizing, ports are turned to face their route's far end; if any turned, phases 1 and 2 run again. → pipeline
Fold / piece
Cutting a frame's long run of ranks into pieces that are packed or stacked to fit the aspect target. → size
Frame
One submachine laid out as its own layered graph: the unit of ordering, sizing, sharding and reuse. → decompose
Grid unit
1/16 pt. Every layout coordinate is an int32 grid unit with |x| ≤ COORD_MAX = 524,287. → principles
Hierarchy-crossing transition
A transition whose ends lie in different submachines. Short if it crosses one border, long if more. → intro
Holder
Where a label may lie: the chart intersected with every state enclosing both ends of its transition (and the region, if the LCA is one). → labels
Inflation retry
On an unreachable route, widen rank_sep, node_sep and sub_sep by 32 units and re-run phases 2–3, up to 8 times. → pipeline
Initial / final
Pseudostates written with *: trans * -> X creates an initial, trans X -> * a final. → intro
Inscribed glyph
A pseudostate drawn as a disc, diamond or H inside its box; routes meet it at face midpoints. → route
Internal / local / external
A transition's kind: whether the arrow crosses its source's border. An internal self-transition has no route at all. → intro
Kick
A structural perturbation (reverse a cycle edge, turn a frame, flip a fold) searched to convergence and kept only if it converges cheaper. → search
Lane
Nudging's group of nearby, overlapping parallel segments, spread apart into tracks. → route
LCA (frame)
The lowest common ancestor: the innermost submachine holding both ends of a transition. Its segment owns the label. → labels
Leader
The invisible half-em offset (96 units) from a label's slide point on its route to an attachment point of its box. → labels
Level 1
Steepest-descent local search over pins: score every move in parallel, take the single best strict improvement, repeat. → search
Level 2
The table of 16 whole-chart phase-2 settings (rows); every row is searched, and the cheapest wins. → search
Loose tier
The label fallback: anchored, inside its holder, uncut by its own route, but allowed over states, bands, boxes or foreign routes. → labels
Memo
A cache keyed on every value a step reads, so a hit is exactly the computed answer and changes only the wall clock. → principles
Net
One routed piece of a transition (one segment) with its ends and waypoints. → route
No-text / real text
The two measurement scales: no space requests at all, or text measured with the bundled font. Never compared across. → principles
Nudging
Post-routing separation of lanes into parallel tracks, ordered to avoid crossings. → route
Pad
A box's interior ring, 128 units on readable. → size
PathBox / PathClear / Placed
The label space request; the arrowhead trim per end; the placed label rectangle layout returns. → intro
Pins
Everything besides the row that a drawing is a function of: rank, cut, reverse, face, side, orient and fold pins. → search
Port / port slot
Where a segment crosses a state's border; reported as {x, y, side, depth}, side 0 left, 1 right, 2 top, 3 bottom. → decompose
Profile
52 integer fields: spacing, type sizes, per-kind minimums, aspect, weights and search knobs (readable, compact). → intro
Pseudostate
Every state kind but Normal: initial, final, choice, junction, fork, join, history, deep history. → intro
Rank / rank pin
A node's column in its frame (its row, in a frame turned to run down). A RankPin holds a state at a chosen rank. → order
Region
Informal name for one submachine of a concurrent state, drawn beside its siblings with a dashed divider. → intro
Row
One Level 2 setting of {box-packer flip, compaction, ratio source, fold}. → search
Scale measure (SM)
min(dar_num / (dar_den · w), 1 / h), compared by cross-multiplying; picks packings and folds. → size
Seat / seating passes
Where a route end attaches on a face, settled by five passes: Attach, Reface, Align, Spread, Separate. → route
Segment
The part of a transition that lies in one frame, between two ports or a port and an endpoint. → decompose
Shard
A unit of parallel work whose count depends only on the model, never on the thread count; results merge in index order. → principles
Shortfall
max(0, gap to own leg + h − gap to nearest foreign leg): the first key of a label's placement, and Tier 2's label_near. → labels
Side (move)
Which border of its state a port sits on; a SidePin fixes it. → search
Space requests
The application's three integer tables (BoxSpace, PathClear, PathBox): the only way content affects layout. → intro
Split graph
Phase 0's output: segments, ports, per-state depth and a process-unique serial. → decompose
Strict tier
A label candidate clear of every wall (foreign states, text bands, placed boxes) and every other transition's legs. → labels
Submachine
A child region of a state that holds states; a document's root is one. → intro
Sweep
One median pass over a frame's ranks, down or up; sweep_count = 8. → order
Tier 0 counts
The eight forbidden counts: through-box, box-overlap, flush, through-region, retrace, vanished, label-over-box, label-over-route. → cost
Transit bend
A bend inside a state the route merely passes through; charged on top of an ordinary bend. → cost
Trunk
The shared final leg of routes into a common destination; not charged as corridor. → cost
