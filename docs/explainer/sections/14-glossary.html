Glossary

Every term on this page in one line, linked to the section that explains it.

Anchor (label)
Midpoint of a route's longest horizontal leg; labels are pulled toward it. → labels
Attachment point
One of eight points on a label box where its leader ends. → labels
Band
Room a state reserves around its submachine area (h_before, h_after, w_before, w_after); every band is an obstacle. → decorated states
Bend
A route vertex where the direction changes; 512 in Tier 2. → cost
Bend node
A dummy node chaining a long edge through an intermediate rank; a routing waypoint. → order
Bend penalty
The router's cost per turn: one rank_sep (576). → route
Boundary node
A port's node on its frame's edge: exits trailing, entries leading. → decompose
BoxSpace
Per state and submachine: text width and four bands around its children. → intro
Brandes–Köpf (BK)
Linear-time, balanced placement of nodes across the ranks. → size
Candidate
One pass from ordering through cost for one row and set of pins. → pipeline
Chaining / cut
A long edge chained through bend nodes; a cut leaves it unchained. → order
Chart cover
Growing the chart rectangle over every route and label before scoring. → size
Choice
A pseudostate drawn as a diamond; routes meet it at a face midpoint. → intro
Clearance
The router's bumper around boxes: node_sep / 3 = 96 units. → route
Composite state
A state with at least one submachine. → intro
Concurrent state
A state with two or more submachines (regions), drawn side by side. → intro
Corridor
Length two routes share on one line, except their common final leg. → cost
Cost (Tier 0, 1, 2)
The objective: forbidden counts, then hints, then weighted terms, compared in order. → cost
Crowding
Parallel routes closer than an em, priced down to zero at one em. → cost
DAR
Desired aspect ratio: 16:10 on readable. → size
Decompose (phase 0)
Cutting transitions at borders into segments and ports, one graph per submachine. → decompose
Degraded route
A net that could not be routed, drawn straight and reported. → route
Determinism contract
Any conforming C++20 toolchain, platform and thread count gives the same bytes. → principles
Em
The font size, 192 units on readable: Tier 2's length unit. → cost
Face (move)
Which side of a box a route end uses; a face pin fixes it. → search
Facing pass
Turning ports toward their route's far end, then ordering and sizing again. → route
Fold / piece
Cutting a long run of ranks into pieces that are packed. → size
Frame
One submachine laid out as its own layered graph. → decompose
Grid unit
1/16 pt; every coordinate is an integer number of them. → principles
Header
A state's name, and under a rule its description, in its h_before band; a wall. → decorated states
Hierarchy-crossing transition
A transition whose ends lie in different submachines. → intro
Holder
Where a label may lie: inside every state enclosing both ends. → labels
Inflation retry
Widening spacing and rerouting, up to 8 times, when a net is unreachable. → route
Initial / final
Pseudostates written *: trans * -> X, trans X -> *. → intro
Inscribed glyph
A pseudostate drawn as a mark inside its box; routes meet face midpoints. → route
Internal / local / external
A transition's kind: whether its arrow crosses the source's border. → intro
Kick
A structural change searched to convergence, kept only if cheaper. → search
Lane
A group of nearby parallel segments that nudging spreads apart. → route
LCA (frame)
The innermost submachine holding both ends of a transition; owns its label. → decompose
Leader
The invisible half-em link from a label's route to its box. → labels
Level 1
Steepest descent over pins: take the best improving move, repeat. → search
Level 2
Sixteen whole-chart sizing settings (rows), each searched; the cheapest ships. → search
Lined face
A face of a state that one of its bands covers; no port sits on it. → decorated states
Loop room
Room below a state's submachine area holding its internal self-transitions, one loop per row. → decorated states
Loose tier
The label fallback: anchored and inside its holder, but may overlap. → labels
Memo
A cache keyed on every value a step reads, so hits are exact. → principles
Net
One routed segment of a transition. → route
No-text / real text
The two measurement scales: no space requests, or measured text. Never compared. → principles
Nudging
Spreading parallel routes into separate tracks after routing. → route
Pad
A box's interior ring: 128 units on readable. → size
PathBox / PathClear
A label's requested box; an end's arrowhead trim. → intro
Pins
Recorded search decisions: rank, cut, reverse, face, side, orient, fold. → search
Port / port slot
Where a segment crosses a state's border, and its reported position. → decompose
Profile
52 integer settings: spacing, sizes, weights, search knobs. → intro
Pseudostate
Any state kind but Normal: initial, final, choice, fork and so on. → intro
Rank / rank pin
A node's column in its frame; a rank pin fixes it. → order
Region
One submachine of a concurrent state. → intro
Row
One Level 2 setting of four sizing knobs. → search
Scale measure (SM)
How large a packing could be drawn at the desired aspect; larger wins. → size
Seat / seating passes
Where a route end meets its box, chosen by six passes. → route
Segment
The part of a transition inside one frame. → decompose
Shard
A unit of parallel work fixed by the model, merged in index order. → principles
Shortfall
How much nearer a label is to a foreign leg than its own. → labels
Side (move)
Which border of its state a port sits on; a side pin fixes it. → search
Space requests
The application's measured sizes: BoxSpace, PathClear, PathBox. → intro
Split graph
Phase 0's output: segments and ports. → decompose
Strict tier
A label clear of every foreign state, band, box and route. → labels
Submachine
A group of states inside a state, or a document's root. → intro
Sweep
One median pass over a frame's ranks, down or up. → order
Tier 0 counts
The nine forbidden counts, such as a route through a box. → cost
Transit bend
A bend inside a state the route only passes through. → cost
Trunk
The shared final leg of routes into one target; not corridor. → cost
